# Pomodoro Timer

A modern, responsive Pomodoro Timer web application built with HTML, CSS, and vanilla JavaScript. The interface uses a polished dark UI, glassmorphism panels, animated progress feedback, keyboard shortcuts, local storage, and practical productivity extras.

## Features

- Pomodoro, short break, and long break modes
- Start, pause, and reset controls
- Animated circular progress ring
- Completed Pomodoro session counter
- Focus minutes and cycle stats
- Dynamic browser title with remaining time
- Sound notification when a session ends
- Random motivational productivity quotes
- Keyboard shortcuts: `Space` to start or pause, `R` to reset
- Local storage for sessions, focus minutes, custom durations, theme, and tasks
- Dark and light theme toggle
- Custom timer durations
- Fullscreen focus mode
- Task list with add, complete, delete, and clear completed actions
- Responsive layout for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- Local Storage API

## How To Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build step, package manager, or framework is required.

## Keyboard Shortcuts

- `Space`: Start or pause the timer
- `R`: Reset the current timer
